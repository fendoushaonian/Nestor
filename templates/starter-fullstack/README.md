# {{name}}

Full-stack starter generated by **Nestor**. The frontend (Vite + TypeScript) is
pre-wired to a Nestor NestJS backend through a typed client that handles the
unified `ApiResponse` envelope, bearer auth, and **automatic token refresh**.

## Run it

1. **Start the backend** (in your Nestor monorepo):

   ```bash
   pnpm dev:api        # serves http://localhost:3000/api
   ```

2. **Configure the API origin** — copy `.env` and adjust if needed:

   ```bash
   # .env
   VITE_API_BASE=http://localhost:3000
   ```

3. **Start the frontend**:

   ```bash
   npm install
   npm run dev
   ```

Open the app, log in with a seeded account, then upload a file and see it listed —
all calls go through `src/lib/nestor.ts`.

## The client

`src/lib/nestor.ts` is a vendored, dependency-free copy of `@nestor/sdk`:

```ts
import { NestorClient } from './lib/nestor'

const api = new NestorClient({ baseUrl: import.meta.env.VITE_API_BASE })

await api.auth.login({ identifier: 'admin', password: '••••••' })
const me = await api.auth.profile()           // bearer attached automatically
const page = await api.files.list({ page: 1 }) // ApiResponse unwrapped to `data`
await api.files.upload(file, file.name)        // multipart, field name `file`
```

Tokens are stored in `localStorage` and refreshed transparently when the access
token expires. Once `@nestor/sdk` is published you can delete the vendored file
and `import { NestorClient } from '@nestor/sdk'` instead — the API is identical.
