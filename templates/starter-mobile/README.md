# {{name}}

A cross-platform mobile app (iOS + Android) scaffolded with
[Nestor](https://github.com/fendoushaonian/Nestor) — React Native + Expo + TypeScript.

## Develop

```bash
npm install
npm run ios       # iOS simulator
npm run android   # Android emulator
npm run web       # run in a browser
```

## Generate code

```bash
npx nestor generate screen Home
npx nestor generate component Card
```
